Setup
  1. Push server.py + dashboard.html to GitHub
  2. Render auto-deploys — no API keys needed!
  3. Install plugin.lua in Roblox Studio Plugins folder
  4. Enable HTTP: Game Settings → Security → Allow HTTP Requests ✅
  5. Set your Render URL in the plugin, copy the token
  6. Paste token in Studio Token field above
  7. Type a prompt → scripts appear in Studio automatically ⚡
