Setup Guide
  1. Get free Gemini key at aistudio.google.com → Get API Key
  2. On Render → Environment → add GEMINI_KEY
  3. Push server.py + dashboard.html to GitHub
  4. In Roblox Studio: install plugin.lua from Plugins folder
  5. Enable HTTP: Game Settings → Security → Allow HTTP Requests
  6. Set backend URL in the plugin, copy the token shown
  7. Paste token in the Studio Token field above
  8. Chat — scripts auto-appear in your Studio Explorer ⚡
